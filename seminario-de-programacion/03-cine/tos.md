- A.S Cinema no se responsabiliza por problemas técnicos, caídas del sistema o errores de funcionamiento que impidan el uso correcto de la app.

POLÍTICA DE PRIVACIDAD Y USO DE DATOS PERSONALES

1. RECOLECCIÓN DE DATOS
La aplicación puede recolectar información mínima, como:
- Nombre (si el usuario lo introduce al reservar).
- Correo electrónico (opcional, si se ofrece funcionalidad de confirmación).
- Selecciones de películas y horarios para mejorar la experiencia del usuario.

2. USO DE LA INFORMACIÓN
- La información se utiliza exclusivamente para brindar el servicio de reserva y mostrar contenido personalizado.
- No compartimos datos personales con terceros sin su consentimiento, salvo obligación legal.

3. SEGURIDAD

4. DERECHOS DEL USUARIO
El usuario tiene derecho a acceder, modificar o eliminar sus datos personales. Puede ejercer estos derechos escribiéndonos a: contacto@as-cinema.com
